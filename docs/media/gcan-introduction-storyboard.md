# GCAN 影片介紹｜分鏡與旁白稿

> 狀態：影片製作規格，並非已完成影片。正式影片必須以真實工作台操作錄影替換示意畫面。

## 影片規格
- 16:9、1080p、繁體中文旁白與字幕。
- 深藍、靛紫、冷白的品牌視覺；清楚、可信，不使用誇大效能或收益宣稱。
- 目標長度 60–75 秒，適合 GitHub 首頁與產品介紹頁。
- 所有功能畫面以實際部署或可重現的本機操作錄製；示範資料必須標示 DEMO。

## 分鏡與旁白
| 時間 | 畫面 | 旁白 |
|---|---|---|
| 00–08 秒 | GCAN 品牌主視覺與全球節點 | Global Citizen AI Network，簡稱 GCAN。我們希望讓 AI 成為更多人能使用、能參與，也能共同改善的公共能力。 |
| 08–18 秒 | 五線架構圖依序點亮 A–E | GCAN 由五條互相協作的開發線組成，每條線都有獨立工作台與清楚責任。 |
| 18–30 秒 | Agent Factory 任務、測試與 CI | Agent Factory 負責規劃、工程執行、測試、修復與交付，每次結果都留下可追蹤的證據。 |
| 30–42 秒 | GCAN Product 與 Predictive Coding | GCAN Product 聚焦真實使用者流程；Predictive Coding 衡量預測、觀測與誤差，讓改善有依據。 |
| 42–54 秒 | Deep Neural 證據面板、Deep Research 來源清單 | Deep Neural 整理可追溯的知識與推理；Deep Research 負責多來源查證、反證與研究報告。 |
| 54–66 秒 | 五線協作閉環、版本與審核標記 | 五線透過版本、來源、測試與接收線審核互相學習；AI 建議不會直接改寫正式環境。 |
| 66–75 秒 | 品牌收尾、GitHub 與產品入口 | 這是一個持續建設中的平台。歡迎查看程式碼、開發紀錄與每一項可驗證成果。 |
