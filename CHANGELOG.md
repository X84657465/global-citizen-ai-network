# Changelog

All notable changes are recorded here. Versions use numeric MAJOR.MINOR.PATCH only.

## 0.2.2 — 2026-11-20

### Added
- Fifth development track E — Deep Research, with a dedicated interactive research workbench at /deep-research.
- Five-track mutual-support governance and evidence-led research responsibilities.
- Research workflow covering question definition, source discovery, source-quality checks, corroboration, counter-evidence and cited synthesis.

### Changed
- Overall integration version and package version advanced to 0.2.2.
- Engineering governance now defines five mutually supporting tracks.

### Verification
- UI source and responsive styles committed to the dedicated development branch.
- The interface currently uses clearly labelled demonstration data and local page state; live search, server persistence and research-agent execution are not connected.
- Exact-head CI and independent review remain required before acceptance.

### Added

### Verification
